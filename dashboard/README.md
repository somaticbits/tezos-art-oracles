# dashboard

Grafana dashboard (`tezos-dashboard.json`) for monitoring a Tezos node (bootstrap status, peers, RPC, operations per block, CPU, memory, I/O) and a TzKT indexer, via Prometheus and [tezos_exporter](https://github.com/ecadlabs/tezos_exporter). It is provisioned by the monitoring stack in [tezos-infra](https://github.com/somaticbits/tezos-infra).
